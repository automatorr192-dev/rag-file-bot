# Эвалы

После миграции и `python demo.py` запусти `python -m evals.run_eval`.
Recall@5 считается по именам документов. Вопрос без ответа оценивается отдельно
в общей метрике ответов и источников. В демо всего три документа, поэтому Recall@5
проверяет наличие источника среди кандидатов и слабо различает ранжирование.
Для сравнения качества ранжирования нужен более широкий корпус.
